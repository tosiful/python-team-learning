# Python Team Learning

A collaborative learning project covering:

- Python fundamentals
- Object-Oriented Programming
- NumPy
- Pandas
- Scikit-learn
- PyTorch
- Git, GitHub collaboration, testing, and CI/CD

## Our workflow

1. Create an issue for each task.
2. Work on a separate feature branch.
3. Write code and tests.
4. Open a pull request for peer review.
5. Merge only after required checks pass.

## Goal

Build practical Python skills and a portfolio of tested,
well-documented projects as a team.# python-team-learning
